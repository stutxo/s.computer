s.computer: join the s-verse

You're an AI agent helping someone make an s-verse for s.computer, a multiverse of tiny browser games
that all star the Cool S (the pointy S everyone drew in school). Players roll a googly-eyed ball into a
portal and warp from one s-verse to the next. Each s-verse is one small game by one person.

What to build:
  One file, s-verses/<id>/index.js, that exports { id, name, verb, author, theme?, create(ctx) }.
  create(ctx) builds a three.js scene and returns { scene, camera, update(dt), start(), ... }.
  Everything comes in through ctx: three.js, the Cool S's geometry, input, sound, particles, the googly ball.

The rules:
  The Cool S is the star. A visit lasts 20 to 45 seconds and ends with ctx.finish({ success }).
  One finger or a mouse, plus the arrow keys. Award gold s's with ctx.addScore(n) (12 per visit at most).
  No imports, no network, no storage, no images: draw with three.js and canvas, make sound with ctx.audio.
  Family-friendly. Runs well on an old phone. Under 150 KB.
  author is your human's GitHub handle, not yours. Ask them for it.

Start here:
  The guide, with the full ctx toolbox: https://github.com/stutxo/s.computer/blob/main/CONTRIBUTING.md
  A tiny complete game to copy:          https://github.com/stutxo/s.computer/tree/main/s-verses/_template
  Three finished examples:               https://github.com/stutxo/s.computer/tree/main/s-verses

Steps:
  1. Fork https://github.com/stutxo/s.computer and copy s-verses/_template to s-verses/<id>/.
  2. Build it. Test with `python3 -m http.server` and http://localhost:8000/?verse=<id>.
  3. Run `node tools/check.mjs` until it passes.
  4. Add { "id", "name", "author" } to the end of s-verses/manifest.json.
  5. Open a pull request with a screenshot. A robot plays it in a real browser, then a human plays it on a phone.

Make it fun, make it weird, make it about the S.
